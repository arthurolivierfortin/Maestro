# 53-A : Decomposition EntryPointExecutor

**Effort** : 2 jours
**Prerequis** : Phase 52 COMPLETE

---

## ERREURS INTERDITES

> **Lire AVANT de coder. Violation = revert immediat.**

1. **NE PAS creer de NativeHandlerRegistry ou ToolHandlerRegistry.** Ce serait un god class deguise. Chaque operation est un block dispatch par `BlockExecutorRegistry`. Un seul registre.

2. **NE PAS laisser de handlers natifs dans NodeExecutionEngine.** Le moteur de nodes est du PUR controle de flux. Quand il rencontre un `blockRef`, il dispatch via `BlockExecutorRegistry`. Il n'execute RIEN lui-meme.

3. **NE PAS casser les workflows existants.** La decomposition doit etre iso-fonctionnelle. Tous les workflows existants (26 workflows) et agents (34 agents) doivent fonctionner IDENTIQUEMENT avant et apres. C'est un refactoring, pas un changement de comportement.

4. **NE PAS modifier les interfaces publiques de l'API.** `POST /api/sessions/{id}/invoke` reste identique. Le point d'entree `StartExecution()` reste public. Ce qui change est l'interne.

---

## Contexte

`EntryPointExecutor.cs` fait **4272 lignes** et melange 3 responsabilites :
1. **Moteur d'execution de nodes** : while, conditional, sequence, parallel, for-each, set-variable, blockRef dispatch
2. **Handlers natifs** : LLM call, shell execute, file write, file read, tree documenter, etc.
3. **Gestion d'etat de session** : execution tree, logs, metrics, artifacts, active block

C'est le meme probleme que AgentBlockExecutor et ToolBlockExecutor : un monolithe qui attire du code.

### Dispatch des nodes

Quand `NodeExecutionEngine` rencontre un node avec `blockRef`, il appelle :

```csharp
var result = await _blockExecutorRegistry.Get(blockType)
    .ExecuteAsync(block, context, inputs, ct);
```

Il ne connait PAS les types de blocks. Il ne sait pas ce qu'est un agent, un tool, ou un workflow. Il orchestre, il n'execute pas.

### Interface

## 4. `EntryPointExecutor` simplifie

Apres extraction, `EntryPointExecutor` ne garde que :

```csharp
public class EntryPointExecutor
{
    private readonly NodeExecutionEngine _engine;
    private readonly ISessionStateManager _stateManager;
    private readonly IBlockDiscoveryService _blockDiscovery;
    private readonly IProjectSessionRepository _repository;

    // Point d'entree public — lance l'execution en background
    public string StartExecution(SessionId sessionId, string entryPoint,
        string workflowId, Dictionary<string, object>? inputs = null)
    {
        var invocationId = Guid.NewGuid().ToString("N")[..12];
        _ = Task.Run(() => ExecuteAsync(sessionId, entryPoint, workflowId, invocationId, inputs));
        return invocationId;
    }

    private async Task ExecuteAsync(...)
    {
        var session = await _repository.GetByIdAsync(sessionId);
        _stateManager.InitializeRuntime(session);

        var block = await _blockDiscovery.GetByIdAsync(workflowId);
        var tree = _stateManager.BuildExecutionTree(block);

        // Dispatch vers BlockExecutorRegistry (agent, workflow, tool, inference)
        var executor = _executorRegistry.Get(block.BlockType);
        await executor.ExecuteAsync(block, context, inputs, ct);

        // Cleanup
        _stateManager.ClearActiveBlock(session);
        await _repository.SaveAsync(session);
    }
}
```

~100 lignes au lieu de 4272.
