# 53-D : Migration agents existants + templates de nodes

**Effort** : 1.5 jours
**Prerequis** : 53-C COMPLETE

---

## ERREURS INTERDITES

> **Lire AVANT de coder. Violation = revert immediat.**
> **Cette sous-phase est la PLUS DANGEREUSE. Un agent sans contexte historique va naturellement vouloir faire ces erreurs.**

1. **NE JAMAIS hardcoder un template par defaut dans AgentBlockExecutor.** Le fallback temporaire (si un agent n'a pas config.nodes → injecter agent-loop-standard) est un PONT DE MIGRATION, pas un feature. Il sera supprime.

2. **NE JAMAIS modifier AgentBlockExecutor pour ajouter du tool dispatch.** Si vous avez envie d'ajouter du code dans AgentBlockExecutor, ARRETEZ et relisez le ADR : `docs/phases/PHASE-53/ADR-AGENT-AS-WORKFLOW.md`.

3. **NE PAS supposer que tous les agents utilisent le meme pattern.** Certains agents ont des tools (→ agent-loop-standard), d'autres n'en ont pas (→ agent-loop-simple), d'autres ont du multi-model (→ agent-loop-planning). Chaque agent doit avoir le BON template.

4. **NE PAS modifier la structure des block.json au-dela de l'ajout de config.nodes.** Les parametres existants (`config.model`, `system-prompt.md`, `config.maxIterations`, etc.) RESTENT.

5. **NE PAS supprimer le code existant de AgentBlockExecutor avant que TOUS les agents migres fonctionnent.** Migration progressive.

6. **NE PAS creer de nouveaux templates au-dela des 3 prevus** (standard, planning, simple). Les templates sont des raccourcis, pas des contraintes.

---

## Principe fondamental

> **La logique des agents se base sur la logique que faisait le code C# avant.** On peut faire exactement la meme logique en blocks — c'est justement ce qui permet la "compilation" future (compresser les blocks en code natif). Les templates de nodes sont une transcription fidele de l'ancien code.

## 1. Creer les templates de nodes

Dans `content/system/templates/agent-nodes/` :

### `agent-loop-standard.json`

Le pattern standard : conversation + LLM + parse + tool dispatch + conditional routing.
**C'est la transcription en nodes de l'ancienne boucle while(true) de AgentBlockExecutor.**

```json
{
  "description": "Standard agentic loop with tool calling",
  "nodes": [
    {
      "id": "init",
      "type": "set-variable",
      "variable": "_agentDone",
      "value": "false"
    },
    {
      "id": "agent-while",
      "type": "while",
      "condition": "{{_agentDone}} != true",
      "maxIterations": "{{maxIterations}}",
      "nodes": [
        {
          "id": "read-conversation",
          "blockRef": "conversation-read",
          "inputs": { "conversationId": "{{_conversationId}}" }
        },
        {
          "id": "llm-call",
          "blockRef": "inference",
          "inputs": { "messages": "{{_nodeResult_read-conversation.messages}}" }
        },
        {
          "id": "append-assistant",
          "blockRef": "conversation-append",
          "inputs": {
            "conversationId": "{{_conversationId}}",
            "role": "assistant",
            "content": "{{_nodeResult_llm-call.content}}"
          }
        },
        {
          "id": "parse-response",
          "blockRef": "response-parser",
          "inputs": { "rawResponse": "{{_nodeResult_llm-call.content}}" }
        },
        {
          "id": "route-response",
          "type": "conditional",
          "condition": "{{_nodeResult_parse-response.type}}",
          "branches": {
            "tool-call": {
              "nodes": [
                {
                  "id": "dispatch-tool",
                  "blockRef": "tool-dispatcher",
                  "inputs": {
                    "toolId": "{{_nodeResult_parse-response.toolId}}",
                    "args": "{{_nodeResult_parse-response.args}}"
                  }
                },
                {
                  "id": "append-tool-result",
                  "blockRef": "conversation-append",
                  "inputs": {
                    "conversationId": "{{_conversationId}}",
                    "role": "user",
                    "content": "{{_nodeResult_dispatch-tool.result}}"
                  }
                }
              ]
            },
            "step-complete": {
              "nodes": [
                { "id": "set-done", "type": "set-variable", "variable": "_agentDone", "value": "true" },
                { "id": "set-result", "type": "set-variable", "variable": "_agentResult", "value": "{{_nodeResult_parse-response.summary}}" }
              ]
            },
            "text": {
              "nodes": [
                { "id": "set-text-result", "type": "set-variable", "variable": "_agentResult", "value": "{{_nodeResult_parse-response.text}}" },
                { "id": "set-text-done", "type": "set-variable", "variable": "_agentDone", "value": "true" }
              ]
            },
            "retry": {
              "nodes": [
                {
                  "id": "nudge-agent",
                  "blockRef": "conversation-append",
                  "inputs": {
                    "conversationId": "{{_conversationId}}",
                    "role": "user",
                    "content": "Your last response was empty or malformed. Respond with a JSON tool call. If done, call step-complete."
                  }
                }
              ]
            }
          }
        }
      ]
    }
  ]
}
```

### `agent-loop-planning.json`

Premiers N iterations avec model planification (opus), reste avec model rapide (sonnet). Meme structure que standard, mais avec condition sur `{{currentIteration}}` pour switcher le blockRef du llm-call.

### `agent-loop-simple.json`

Pas de tool dispatch, juste conversation + LLM + reponse directe. Le `route-response` n'a que les branches `step-complete`, `text`, et `retry`.

## 2. Migrer les agents existants

Pour chaque `*.agent.block.json` existant (34 agents) :
- Ajouter `config.nodes` copie depuis le template appropriate
- Les parametres existants (`config.model`, `system-prompt.md`, `config.maxIterations`) restent
- `AgentBlockExecutor.PrepareExecutionAsync()` lit ces parametres et les passe aux nodes

**Fallback temporaire** : Si un agent n'a pas de `config.nodes`, `AgentBlockExecutor` injecte le template `agent-loop-standard` automatiquement. Ce fallback est TEMPORAIRE et sera supprime une fois tous les agents migres.
