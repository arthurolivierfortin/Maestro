# Phase 33 : Meta-optimisation et Agent Creator

**Statut** : A faire
**Prerequis** : Phase 32 COMPLETE (tiers publies, maestro check fonctionnel)
**Objectif** : Automatiser l'adaptation et l'optimisation des workflows, et creer un agent qui cree des agents.

---

## Vision

Phase 33 est le sommet de la pyramide Maestro :
- **`maestro adapt`** : tester automatiquement des modeles locaux comme substituts
- **Agent Creator** : un agent qui cree d'autres agents (meta-programmation)
- **`maestro optimize`** : meta-workflow qui optimise les workflows existants

---

## Sous-phases

| Phase | Titre | Objectif |
|-------|-------|----------|
| 33-A | `maestro adapt` — adaptation automatique | Tester des substituts automatiquement |
| 33-B | Agent Creator — agent qui cree des agents | Meta-creation d'agents |
| 33-C | `maestro optimize` — meta-workflow | Optimisation recursive |

---

## Principe

Ces features sont les plus avancees de Maestro. Elles ne seront creees que quand les phases precedentes sont stables et testees. Pas de travail premature ici.

Les plans detailles de cette phase seront crees quand les phases 30-32 seront terminees. Les issues ci-dessous sont des specifications de haut niveau, pas des plans d'implementation.
