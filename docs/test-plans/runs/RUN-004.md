# PHASE 4 : Exécution Agent avec Context

## Test 4.1 : Agent avec Context Sliding-Window - ÉCHEC (Problème Modèle)

**Commande :**
```bash
node C:/Meastro/tools/maestro-cli/index.js run simple-task-executor \
  --input 'task=List files in C:/Meastro' \
  --input 'workingDir=C:/Meastro'
```

**Résultat :**
```
✅ Block executed successfully in 109618ms

📋 Logs:
  Using model: HuggingFaceTB/SmolLM2-1.7B-Instruct
  Context strategy: sliding-window, maxTokens: 2048  ← CONTEXT ACTIF!
  Agent iteration 1/5
  LLM response: {"tool":"list_files","args":{"path":"/home/user/Documents"}}
  Tool call detected: list_files
  Tool result: Error: Cannot find path 'C:\home\user\Documents'
  Agent iteration 2/5
  LLM response: {...same wrong path...}
```

**Problème Identifié :**
Le modèle SmolLM2 :
- ✅ Produit du JSON valide
- ✅ Appelle les tools correctement
- ❌ **Ignore les inputs utilisateur** (utilise "/home/user/Documents" au lieu de "C:/Meastro")
- ❌ **Pattern mémorisé** : Le modèle a appris un pattern par défaut lors du fine-tuning

**Confirmation :** Le context management fonctionne (log "Context strategy: sliding-window"), mais le modèle n'est pas assez performant pour lire/utiliser les inputs de l'utilisateur.
