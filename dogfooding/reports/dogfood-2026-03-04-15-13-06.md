## Broken Features

1. **Agent response never arrives**: The core feature — asking the agent a question and getting a response — does not work. The pipeline completes up to Execute Agent, then times out. The LLM provider shows as healthy, so the issue is in the AgentBlockExecutor → LLM call chain.

2. **Sidecar ESM bug**: `MaestroSidecar` fails with `__dirname is not defined`. This blocks auto-start of services for users who don't have them pre-running.

3. **Spaces session list empty**: Despite 141 sessions existing (visible on Home), Spaces shows 0. This is a data source or filtering bug.

## Suggestions

1. **Add streaming/progress for Execute Agent**: Show LLM thinking status, token count, or at minimum a timer showing elapsed seconds.
2. **Fix the Spaces data source**: It should show the same sessions as Home, or clearly indicate its scope.
3. **Add a getting-started hint**: "New here? Press ? for help" or a brief onboarding on first launch.
4. **Show ✗ for failed pipeline steps**: Don't leave the pending indicator (…) after a timeout.
5. **Add session cleanup**: Bulk delete old sessions from Spaces or Home.
6. **Fix sidecar ESM**: Replace __dirname with import.meta.url pattern.
7. **Deduplicate models**: Show version/alias to distinguish duplicate model names.
