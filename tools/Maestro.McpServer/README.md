# Maestro.McpServer (skeleton)

This folder will host the `Maestro.McpServer` project which exposes Maestro tools/resources via the Model Context Protocol (MCP).

Planned tools:
- `execute-workflow`
- `list-workflows`
- `get-workflow`

Scaffold a .NET project or Node-based MCP server depending on preferred implementation. Add stdio transport for VS Code extension integration.
