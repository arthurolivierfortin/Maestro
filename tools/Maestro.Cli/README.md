# Maestro.Cli (skeleton)

This folder will host the `Maestro.Cli` project. Create a .NET console project here and implement the following commands:

- `maestro execute <workflow-id>`
- `maestro list`
- `maestro validate <workflow-id>`

Support `--mock` and `--input key=value` flags.

To scaffold locally:

```powershell
dotnet new console -n Maestro.Cli
```
